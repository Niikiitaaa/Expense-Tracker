# Expense Tracker

A Python-based expense tracker that helps users record expenses and refunds/cash inflows while storing data permanently using CSV files.

## Features

* Add Expense Transactions
* Add Refund / Cash Inflow Transactions
* Categorize Transactions (Food, Travel, Shopping, Bills, Other)
* Store Data in CSV Files
* View Complete Transaction History
* Generate Net Balance Reports
* Clear All Transaction History
* Input Validation for User Entries

## Technologies Used

* Python
* CSV Module
* File Handling

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

python main.py
